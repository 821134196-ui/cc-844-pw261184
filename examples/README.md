# Example inputs

Generated by `gen.py` (run `python3 examples/gen.py` to rebuild).

| File | Purpose |
|---|---|
| `index.json` | Entry image with a single `linux/amd64` manifest |
| `index-v2.json` | Same application, one layer changed (for `diff`) |
| `index-layout.json` | Entry whose manifest lives in an OCI layout directory |
| `deps.json` | Local artifact registry plus a `deps` edge from layer B |
| `manifests/` | OCI image manifests; one layer is a nested image manifest |
| `nested/` | The nested base image's manifest and config |
| `layers/`, `artifacts/` | Local blobs referenced by the manifests and deps |
| `layout/` | A real OCI layout (`index.json` + `blobs/sha256/…`) |

Try:

```bash
python3 -m offlinepack plan  --index examples/index.json --deps examples/deps.json --target linux/amd64
python3 -m offlinepack build --index examples/index.json --deps examples/deps.json --target linux/amd64 --out /tmp/a
python3 -m offlinepack build --index examples/index-v2.json --deps examples/deps.json --target linux/amd64 --out /tmp/b --reuse-from /tmp/a
python3 -m offlinepack diff /tmp/a /tmp/b --html /tmp/preview.html
```
